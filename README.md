# Gondegan League: راهنمای انتشار روی Vercel

## ساختار فایل‌ها

```
gondegan-league/
├── public/
│   ├── index.html      صفحه اصلی
│   ├── style.css       ظاهر (liquid glass)
│   ├── app.js          کل منطق برنامه
│   └── img/            h1.jpg و h2.jpg (هدر) و about.jpg (بخش About)
├── api/
│   ├── state.js        خواندن (برای همه) و ذخیره (فقط مدیر) اطلاعات لیگ
│   ├── auth.js         بررسی رمز مدیر
│   └── _lib.js         ابزار مشترک (اتصال به دیتابیس و بررسی رمز)
├── package.json
├── vercel.json
└── README.md
```

این برنامه به Claude نیازی ندارد. اطلاعات لیگ روی یک دیتابیس رایگان (Upstash Redis) ذخیره می‌شود و همه‌ی بازدیدکننده‌ها همان را می‌بینند.

## مرحله ۱: آپلود روی GitHub
1. در github.com یک Repository جدید بسازید (مثلاً `gondegan-league`).
2. همه‌ی فایل‌ها و پوشه‌های این پروژه را در ریشه‌ی Repository آپلود کنید (Add file، Upload files). پوشه‌های `public` و `api` باید در ریشه باشند.

## مرحله ۲: ساخت پروژه در Vercel
1. در vercel.com با GitHub وارد شوید.
2. Add New، Project را بزنید و Repository را Import کنید.
3. تنظیمات را دست نزنید (Framework: Other) و Deploy بزنید.

## مرحله ۳: وصل کردن دیتابیس
1. در صفحه‌ی پروژه به تب **Storage** بروید.
2. از Marketplace گزینه‌ی **Upstash Redis** (طرح رایگان) را انتخاب و به همین پروژه وصل کنید.
3. Vercel خودش متغیرهای `KV_REST_API_URL` و `KV_REST_API_TOKEN` را اضافه می‌کند.

## مرحله ۴: تغییر رمز مدیر
رمز پیش‌فرض `gondegan4ever` است. برای امنیت بهتر آن را عوض کنید:
1. Settings، Environment Variables را باز کنید.
2. متغیر `ADMIN_PASSWORD` را با رمز دلخواه اضافه کنید.

## مرحله ۵: Redeploy
بعد از مراحل ۳ و ۴ در تب Deployments آخرین Deploy را Redeploy کنید. بعد از آن لینک سایت آماده است.

## نحوه‌ی کار
- **بازدیدکننده:** فقط می‌بیند. اطلاعات هر ۳۰ ثانیه خودکار به‌روز می‌شود.
- **مدیر:** دکمه‌ی «مدیر» بالای صفحه، وارد کردن رمز، و ویرایش. تغییرات حدود ۲ ثانیه بعد خودکار روی سرور ذخیره می‌شود.
- **امنیت:** رمز روی سرور بررسی می‌شود و بدون آن هیچ‌کس نمی‌تواند اطلاعات را عوض کند.

## اجرای محلی
- فقط برای دیدن ظاهر: فایل `public/index.html` را باز کنید. در این حالت اطلاعات فقط روی همان مرورگر ذخیره می‌شود.
- برای تست کامل: `npm i -g vercel` و بعد در پوشه‌ی پروژه `vercel dev`.
